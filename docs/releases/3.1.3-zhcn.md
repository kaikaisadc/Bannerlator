# Bannerlator 3.1.3-zhcn

Run Windows apps and games on Android — no PC and no root required.

**这是 Bannerlator 3.1.3-pre2 的简体中文界面构建。** 在完全保留上游功能与更新的前提下，新增 `values-zh-rCN` 资源覆盖：**1141 条界面文案全部汉化**，包括所有设置项、对话框、错误提示与 247 条长帮助文本。系统语言为简体中文时自动生效；Android 13 及以上也可在系统设置中为本应用单独选择语言。应用名显示为「Bannerlator Bionic 中文版」。

> ⚠️ **本构建只添加中文语言资源，未改动任何上游文件。** 少数会被程序解析的下拉选项（驱动 / 包装器 / 模拟器名称）仍保留英文以免破坏逻辑；Wine / Proton 内部的 Windows 界面不在本次范围内。

> 📘 **New to LSFG Native? Read the plain-language guide: [LSFG Native Made Simple](https://the412banner.github.io/Bannerlator/lsfg-native-guide.html)** — why Max FPS × multiplier has to fit your screen's refresh rate. The same rule applies to **Win-FG Native**, which always runs at 2×.

# What's New — everything since 3.1.2

## 🇨🇳 完整简体中文界面

**本次构建把应用界面翻译成简体中文。** 采用纯新增语言资源（`app/src/main/res/values-zh-rCN/`）的方式，不修改任何上游文件，因此可持续合并上游更新而不产生冲突；上游新增的字符串在未翻译前会自动回退显示英文。

- **1141 条文案全部汉化**：容器与快捷方式管理、图形 / 音频 / 输入设置、下载与内容安装、存档管理、包装器管理、GOG / Steam 登录流程等。
- **247 条长帮助文本**（每个「?」里的说明）一并翻译，保留原有的加粗与换行格式。
- **应用名**：`app_name` 显示为「Bannerlator Bionic 中文版」。
- **生效方式**：跟随系统语言（简体中文）。Android 13+ 可在「设置 → 应用 → Bannerlator → 语言」单独选择。
- ✅ **已验证**：在 GitHub Actions 上以 `zh-cn` 分支完成三个 flavor（standard / ludashi / pubg）的 release 构建，资源编译通过。
- ⚠️ **未逐条人工精校**：翻译以 Winlator 圈惯用术语校对为主，如遇用词不准欢迎反馈。
- **有意保留英文**：会被程序解析的少数下拉项（`graphics_driver_entries`、`dxwrapper_entries`、`emulator_entries` 等），以及 Wine / Proton 内部界面，以免破坏匹配逻辑。

## 🔧 Smaller

- 新增 `scripts/zh-sync.py`：合并上游后可一键列出新增或失效的翻译 key。

## ⚠️ Carried over — still open

- **仅界面汉化**：Wine / Proton 内部的 Windows 对话框（winecfg、安装程序等）仍为英文，属上游镜像构建链，暂未处理。
- **非官方构建**：本 Release 由个人 fork 构建，并非上游 The412Banner/Bannerlator 的官方发布。
